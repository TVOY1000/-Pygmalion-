### 2. Акт 1 (ПЛАН): Эмиссия У.Е.

| Параметр | Было (Gemini) | Стало (Canon) |
|----------|---------------|---------------|
| **Выбор триад** | Линейно (3→T1, 6→T1+T2) | **Свободный выбор любой** ✅ |
| **У.Е. №21** | При нечётном числе | **Только после ≥1 триады** ✅ |
| **Канонические числа** | 3,4,6,7,9,10,12,13 | **3,4,6,7,9,10,12,13** ✅ |

**Формула расчёта:**
```javascript
// СВОБОДНЫЙ ВЫБОР (не линейно!)
const pendingAmount = (selectedTriads.length * 3) + (selectedExtra ? 1 : 0);

// У.Е. №21 доступна ТОЛЬКО после ≥1 триады
const toggleExtra = () => {
  if (selectedTriads.length === 0) return;  // Блокировка
  setSelectedExtra(prev => !prev);
};
```

### 3. Таймер сгорания

| Параметр | Было (Gemini) | Стало (Canon) |
|----------|---------------|---------------|
| **Точка отсчёта** | От момента эмиссии | **Привязка к 19:56** ✅ |
| **Мин. срок** | 28 часов | **Мин. 4 часа, макс. 28** ✅ |

**Формула:**
```javascript
const BURN_REFERENCE_HOUR = 19;
const BURN_REFERENCE_MINUTE = 56;
const MIN_BURN_HOURS = 4;
const MAX_BURN_HOURS = 28;

// Вычисление времени сгорания
const now = new Date();
const burnRef = new Date();
burnRef.setHours(BURN_REFERENCE_HOUR, BURN_REFERENCE_MINUTE, 0, 0);

if (now > burnRef) {
  burnRef.setDate(burnRef.getDate() + 1);  // Завтра
}

const minBurnTime = new Date(now.getTime() + MIN_BURN_HOURS * 60 * 60 * 1000);
const actualBurnTime = burnRef > minBurnTime ? burnRef : minBurnTime;
```

### 4. Формула репутационного веса

**Каноническая формула:**
```
Вес = (Отдано × 2) + (Принято × 1) − (Сгорело × 1)
```

**Реализация:**
```javascript
const reputationWeight = (givenTotal * 2) + (receivedTotal * 1) - (burnedTotal * 1);
```
