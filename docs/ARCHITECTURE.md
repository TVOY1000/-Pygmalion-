## 🚀 Приоритетные задачи (автоматизация)

### Задача 1: Установка WSL2
```powershell
# От имени администратора
wsl --install
# Перезагрузить компьютер
shutdown /r /t 0
```

### Задача 2: Установка Node.js v20 (канон)
```powershell
winget install CoreyButler.NVM
nvm install 20.18.0
nvm use 20.18.0
```

### Задача 3: Обновление Windows
```
Параметры → Обновление и безопасность → Windows Update
Требуется сборка ≥19044
```

### Задача 4: Docker Desktop
```
Скачать: https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe
Установить с WSL2
```
