## 🚀 Пошаговая инструкция

### Шаг 1: После установки Windows

1. **Запустите браузер** и убедитесь, что есть интернет
2. **Скопируйте файл** `pygmalion_backup.zip` обратно на диск `C:\`
   - Если переустанавливали с флешки — скопируйте с неё
   - Если есть внешний диск — перенесите оттуда

### Шаг 2: Распакуйте проект

Откройте **PowerShell** (нажмите `Win + X` → выберите PowerShell):

```powershell
# Создайте папку
New-Item -ItemType Directory -Path "C:\pygmalion" -Force

# Распакуйте архив
Expand-Archive -Path "C:\pygmalion_backup.zip" -DestinationPath "C:\pygmalion" -Force

# Проверьте содержимое
Get-ChildItem C:\pygmalion
```

### Шаг 3: Установите Git (для работы с репозиторием)

```powershell
# Через winget (рекомендуется)
winget install Git.Git

# Или скачайте с https://git-scm.com/download/win
```

### Шаг 4: Настройте Git

```powershell
cd C:\pygmalion

git config --global user.name "Ваше Имя"
git config --global user.email "ваш@email.com"
```

### Шаг 5: Откройте проект

**Варианты:**

| Программа | Команда |
|-----------|---------|
| VS Code | `code C:\pygmalion` |
| Блокнот | `notepad C:\pygmalion\index.html` |
| Терминал | `cd C:\pygmalion` |

## 🔧 Установка WSL (если нужно)

Если ставите **Windows 11** и нужен Linux:

```powershell
# 1. Включите компоненты (от имени администратора)
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 2. Перезагрузитесь
shutdown /r /t 0

# 3. После перезагрузки установите WSL
wsl --install

# 4. Установите Ubuntu
wsl --install -d Ubuntu
```

> ⚠️ **Важно:** В BIOS должна быть включена виртуализация (Intel VT-x / AMD-V)

## 🆘 Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| Архив не распакуется | Скачайте 7-Zip: `winget install 7zip.7zip` |
| Нет прав на папку | Запустите PowerShell от имени администратора |
| Git не работает | Перезапустите терминал после установки |
| WSL не ставится | Проверьте BIOS → включите виртуализацию |
