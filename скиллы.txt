Вот основные моменты нашего обсуждения:
1. MCP-серверы (Model Context Protocol)
В начале нашего диалога мы анализировали топ-100 серверов на mcpmarket.com и выбрали те, которые необходимы для инфраструктуры Pygmalion / К.Р.И.С.Т.А.Л.Л. [история переписки]:
•	PostgreSQL MCP: Для прямого взаимодействия модели с базой данных и реестром ro.DAG [история переписки].
•	Docker MCP: Для управления контейнерами Activepieces и Apache NiFi через терминал [история переписки].
•	FileSystem (Local) MCP: Для работы с Offline-артефактом и редактирования локальных файлов кода [история переписки].
•	GitHub MCP: Для ведения «Летописи» кода и управления репозиторием [история переписки].
•	Lucide / SVG MCP: Для генерации иконок канонического знака и «Цветка Жизни» [история переписки].

Мы составили подробный перечень рекомендуемых навыков (библиотек), необходимых для реализации 4-х протоколов (ПЛАН, ТОК, КОЛ, ВЕС):
